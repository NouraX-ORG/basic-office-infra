# NoMail folder

NoMail (Nourax mail) keeps email attachments here:

- `Sent/<year-month>/` - big files you attached to sent mail. The recipients get a download link.
- `Received/<year-month>/` - attachments you saved from received mail.
- `Images/<year-month>/` - pictures used inside designed (HTML) emails.

Deleting a file here breaks the link in any email that points to it.
